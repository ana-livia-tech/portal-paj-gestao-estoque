 Portal de Gestão de Estoque — Projeto PAJ

 Sobre o projeto

O Portal de Gestão de Estoque foi desenvolvido com o objetivo de simplificar a comunicação e facilitar o acesso às informações de estoque da operação brasileira da PAJ.

A solução reúne, em um único ambiente, duas ferramentas desenvolvidas para apoiar a rotina operacional: o Controle de Estoque e o Resumo Diário de Estoque.

O projeto surgiu da necessidade de organizar informações, facilitar o acompanhamento das movimentações e tornar a comunicação sobre os estoques mais simples e objetiva.

 Funcionalidades

 1. Controle de Estoque
- Organização das quantidades por modelo e local.
- Visualização dos totais.
- Atualização e geração de arquivos com os dados preenchidos.
- Interface adaptada para facilitar a consulta e o preenchimento.

 2. Resumo Diário de Estoque
- Registro de vendas e pedidos.
- Acompanhamento de devoluções em andamento.
- Registro de devoluções recebidas e contabilizadas.
- Registro de outras alterações no estoque local.
- Suporte aos idiomas português, inglês e alemão.
- Geração e compartilhamento de resumos.

 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Netlify — publicação e hospedagem
- GitHub — versionamento e organização do código

 Objetivos alcançados

- Simplificação da comunicação sobre os estoques.
- Centralização do acesso às ferramentas.
- Organização das informações operacionais.
- Padronização da apresentação e da utilização dos recursos.
- Disponibilização de ferramentas digitais de apoio à rotina.

 Observação técnica

O projeto utiliza arquivos HTML, CSS e JavaScript, com armazenamento e operações locais no navegador. Não possui banco de dados centralizado nem sincronização automática entre diferentes computadores.

Projeto desenvolvido como aplicação prática de desenvolvimento web e melhoria de processos.
