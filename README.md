# Portal de Gestão de Estoque — Projeto de Portfólio

Projeto web estático que reúne duas ferramentas de apoio ao acompanhamento de estoque: controle de quantidades por modelo/local e registro de resumo diário.

## Funcionalidades
- Página inicial com navegação para as duas ferramentas.
- Controle de quantidades com cálculo de totais e opção de baixar uma cópia HTML atualizada.
- Resumo diário com campos para vendas/pedidos, devoluções e outras alterações, suporte a português, inglês e alemão e recursos locais de cópia/salvamento/baixar HTML.

## Tecnologias
HTML, CSS e JavaScript.

## Como executar
Baixe os arquivos e abra `index.html` em um navegador. Não é necessário instalar dependências.

## Observação sobre dados
Esta versão de portfólio foi preparada sem as quantidades e os registros operacionais preenchidos na versão de trabalho. Os dados inseridos pelo usuário são tratados localmente pelo navegador/arquivo. Esta demonstração não possui autenticação, banco de dados centralizado ou sincronização automática entre computadores.

## Estrutura
- `index.html` — página inicial.
- `controle-estoque.html` — ferramenta de controle de quantidades.
- `resumo-diario.html` — ferramenta de resumo diário.
